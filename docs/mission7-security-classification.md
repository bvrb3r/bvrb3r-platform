# Mission 7 security classification

Historical policy text is not treated as an active authority path merely because an obsolete enum literal remains in a predicate. It is release-blocking only when a noncanonical profile can exist or the database canonical-role guard is absent. Mission 7 therefore measures both the literal inventory and the active-path count. The literal inventory remains visible; the active-path count must be zero.

Anonymous broad access, missing RLS, unsafe SECURITY DEFINER search paths, public execution of SECURITY DEFINER functions, exact duplicate policies, and noncanonical profile rows remain critical failures.
