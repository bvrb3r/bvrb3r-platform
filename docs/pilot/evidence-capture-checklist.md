# Pilot Evidence Capture Checklist

Date: 2026-07-05

This checklist defines what evidence is captured during each pilot session.

V1 is not public launch ready; pilot execution is gated on RC evidence closure.

## Per-Session Capture

| Evidence | Actor | Format | Destination | Review cadence |
| --- | --- | --- | --- | --- |
| Session start confirmation | Founder | Written note | Pilot evidence folder | Before session |
| Account role labels | Founder | Screenshot or note | Pilot evidence folder | Before session |
| Device and browser details | Architect | Screenshot or note | Pilot evidence folder | Before session |
| Client path observations | Architect | Screenshot + notes | Architect review packet | During session |
| Barber path observations | Architect | Screenshot + notes | Architect review packet | During session |
| Shop Owner path observations | Architect | Screenshot + notes | Architect review packet | During session |
| Support issue evidence | Actor + Architect | Support thread id + screenshot | Pilot evidence folder | During session |
| Notification consent posture | Architect | Screenshot + note | Pilot evidence folder | During session |
| Booking or kiosk issue | Founder + Architect | Screenshot/photo + route | Pilot evidence folder | Immediate |
| Money confusion | Founder | Screenshot + written decision | Pilot evidence folder | Immediate |
| Pause/resume decision | Founder | Written decision | Pilot evidence folder | Immediate |
| Session closeout | Founder + Architect | Summary note | Pilot evidence folder | End of session |

## Architect Review

Architect reviews evidence for:

- missing proof
- failed proof
- role confusion
- support escalation gaps
- notification promise gaps
- booking or confirmation confusion
- device/kiosk issues
- any money-state uncertainty

## Follow-Up Work Creation

Every issue becomes follow-up work only after evidence is captured with:

- actor
- role
- route
- expected behavior
- actual behavior
- evidence file or note
- owner lane
- severity
- recommended next action

## Evidence Destination

The founder must name the evidence destination before execution. If no
destination is named, pilot execution remains pending.
